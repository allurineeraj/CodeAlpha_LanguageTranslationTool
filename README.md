# Language Translation Tool

A Python desktop and web application built using Streamlit, deep-translator API, and gTTS to translate text across multiple global languages with audio playback.

## Features
- Automatic language detection or manual source selection
- Support for 100+ global languages
- Integrated Text-to-Speech audio output
- Clean and responsive browser user interface
